# 🛡️ Phishing Detection Suite

An enterprise-grade Phishing Detection Suite built with Flask, SQLite, and Machine Learning lexical analysis, integrated with the VirusTotal API.

## 🚀 Features
* **URL Analysis:** Scans URLs for malicious patterns and lexical threats using ML.
* **VirusTotal Integration:** Cross-verifies threat intelligence via external API.
* **Scan History:** Tracks and logs previous lookups securely using SQLite.
* **Clean Interface:** Built with Flask for smooth navigation and real-time results.

## 🛠️ Tech Stack
* **Backend:** Python, Flask
* **Database:** SQLite
* **APIs:** VirusTotal API
* **ML / Analysis:** Lexical feature extraction
